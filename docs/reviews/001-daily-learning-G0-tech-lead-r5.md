### 6. 審査と権限、月の費用、時間の枠
- 審査と権限：
  - App Store の審査はありません。
  - 求める権限は `persist()` だけで、今と変わりません。通知、バックグラウンドの処理、カメラ、位置、外部の AI への送信はありません。
  - CSP の文字列は変えずに済みます。図は HTML と CSS、キャラクターは同じ origin の PNG か、インラインの SVG で描くので、`img-src 'self'` の範囲です。
  - 法務：キャラクターは独自に描き、Undertale などの既存作品のキャラクター、素材、フォントを使わないことが要ります（要修正 3）。
- 月の費用：利用者 1,000 人あたり 0 円です。
  - 内訳の見込み：1 人あたり月に、初回 約 0.5 MB、版の更新 4 回 × 約 0.24 MB、sw.js の確認の分を足して約 1.5 MB。1,000 人で約 1.5 GB です。

  - 外部の API の費用はありません。
- 時間の枠の 4 週：作れる見込みです［推測］。
  - 実装は、問題と返しの画面、段階の規則の置き換え、スキーマ、図の 6 型、キャラクター、分けて読む処理と SW で、約 1.5 週。
