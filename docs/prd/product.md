# プロダクト定義（product.md）

- 書いた役：pdm　日付：2026-10-29
- 状態：初版（`001-personal-learning-loop` 着手時）

根拠にはすべて印を付ける：［実データ］［公開情報 URL］［推測］。

## 1. 対象の層
- **コア対象（最初の1人＝自分自身）**：日々の業務や技術記事・ドキュメント・コードリーディングで新しい知見に触れているが、「読んだだけで終わり、設計判断や障害対応の場面で引き出せない」「カード作りや復習管理が面倒で続かない」と感じている実践志向のソフトウェアエンジニア［実データ .claude/org/app.json］［推測］。
- **広げる対象**：基礎文法を終え、設計・アーキテクチャ・トレードオフ判断・技術トレンドを取り込みながらシニア／テックリード層へ成長したい開発者［推測］。

## 2. 中心の Job
- **Job ストーリー**：業務や日々の情報収集で新しい技術記事や設計の知見に触れたとき、手作業でノート整理や問題作りに時間をかけずに自分の血肉として定着させ、成長の手応えを得たい。そうすれば、忙しい毎日でも挫折せず、実務の設計判断や障害対応で即座に引き出せる圧倒的なプロフェッショナルに成長できる［実データ .claude/org/app.json］［推測］。
- **機能の面**：外部で学んだ記事URLやメモを最小の手間で取り込み、自分の専門領域に紐づいた「プロの思考（設計・障害・トレードオフ）を問う問題」と「忘却曲線に基づく復習」に変換して1日3分（180秒）以内で消化できる［推測］。
- **気持ちの面**：「今日も成長した」という経験値（XP）・スキルツリーの可視化によって、義務感ではなくゲームのように楽に続けたくなる［実データ .claude/org/app.json］［推測］。
- **人の目の面**：単なる用語暗記ではなく、設計の理由やトレードオフを自分の言葉で説明できるエンジニアとして周囲から信頼される［推測］。

## 3. 対象のストアの国と言語
- **対象の国**：`JP`（日本）［推測］
- **対応言語**：日本語（`ja`）を主とし、英語（`en`）の技術用語・記事取り込みおよびUI文言キーに対応する［推測］。
- **提供形態（現在）**：まずは自分自身が毎日ブラウザから使えるローカル/Webバックエンド（`stacks: ["backend"]`）として構築し、将来のストア公開（iOS等）でも審査基準（4.2 / 4.3(b) / 2.3）に適合する設計とする［実データ .claude/org/app.json］。

## 5. 位置づけの1文
既存の教材消化アプリ（Progate・プロ単）や手動カード作成の暗記ツール（Anki・reminDO）とは異なり、**エンジニアが日々外部で触れる記事・メモ・トレンドをそのまま取り込み、3秒以内に「設計・障害・トレードオフを問う実践思考1問」と「忘却曲線レビュー」および「6領域のスキル経験値（XP）」へ変換して、1日3分でプロの思考力を鍛え続ける個人専用の育成エンジン**である［実データ .claude/org/app.json］［推測］。

## 6. North Star と入力指標
- **North Star（1つ）**：
  - **週間定着プロ思考ループ達成数**：直近7日間において、外部学習から生成された「実践思考問題」または「忘却曲線レビュー」に回答し、記憶間隔が次回へ延長（`grade >= 3` または思考問題クリア）された件数（個人利用時は週5件以上、複数ユーザー時は週3件以上達成したアクティブ学習者数）［推測］。
- **入力指標（4個）**：
  1. **日次3分学習ループ完了率（7日間移動平均）**：開始した日次学習セッションのうち、180秒以内に「本日の実践思考問題1問＋期限到来カード（最大5枚）」の回答を完了した割合（`001-personal-learning-loop` が動かす指標）［推測］。
  2. **外部学習インプットの即時変換率**：ユーザーが投入した記事URL・学習メモのうち、3秒以内にスキル領域判定・経験値（XP）付与・実践思考問題1問・忘却曲線カードの4点すべてが生成された割合［推測］。
  3. **忘却曲線レビュー48時間以内消化率**：復習期限（`next_review_at`）が到来したカードのうち、48時間以内に回答されて放置（積読化）されなかった割合［推測］。
  4. **6領域スキルマップの隔週アクティブ領域率**：6つの専門領域（設計・アーキテクチャ、バックエンド・API、データ・DB、インフラ・信頼性、セキュリティ、技術トレンド）のうち、直近14日間でXPが1以上加算された領域の割合［推測］。
